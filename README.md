# Nand2Tetris Project

Projeto desenvolvido como parte do curso **Nand2Tetris**, com o objetivo de construir um computador completo a partir de portas lógicas básicas até a execução de programas de alto nível.

## Sobre o projeto

O Nand2Tetris (From NAND to Tetris) é um curso que ensina como funciona um computador desde o nível mais baixo (hardware) até o mais alto (software).

Neste repositório estão implementações de:

* Portas lógicas básicas (AND, OR, NOT, etc.)
* Componentes combinacionais (Mux, Demux, etc.)
* Componentes sequenciais (Flip-Flops, registradores, memória)
* CPU
* Máquina virtual (VM)
* Compilador (dependendo do progresso)

## Tecnologias utilizadas

* HDL (Hardware Description Language do curso)
* Linguagem Jack (para níveis mais avançados)
* Ferramentas oficiais do Nand2Tetris

## Estrutura

```
/projects
  /01 - Portas lógicas básicas
  /02 - Lógica combinacional
  /03 - Lógica sequencial
  /04 - Linguagem de máquina
  /05 - Arquitetura do computador
  /06+ - VM e compilador
```

## Como executar

1. Baixe as ferramentas do curso (Hardware Simulator / CPU Emulator) ou execute pela IDE online
2. Abra o arquivo `.hdl` desejado
3. Execute os testes (`.tst`) fornecidos
